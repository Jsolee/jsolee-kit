## Motion, 3D, components

- [igloo.inc](https://www.igloo.inc): one 3D object that transforms with scroll, HUD labels anchored with lines.
- [motionsites.ai](https://motionsites.ai): motion-heavy sites (for example "Particle Self", a particle bust). Their free [Claude skill](https://github.com/Motionsites-AI/claude-skill) is worth reading for `references/techniques/` (video loops, scroll stories, text motion, Three.js, with code) and the screenshot-and-fix loop in `references/review.md`. Don't install it as is: it ends every reply with an ad for their paid plan, and its examples lean on liquid glass and serif italics.
- [docs.pmnd.rs](https://docs.pmnd.rs): React Three Fiber and drei docs.
- [transitions.dev](https://transitions.dev): essential UI transitions for web apps, to copy or to use through its [skill](https://github.com/Jakubantalik/transitions.dev). Free and paid.
- [storytold/effectcraft](https://github.com/storytold/effectcraft): open source motion graphics and compositing.
- [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos): code-rendered videos and the prompts behind them. The impressive ones are Three.js + shaders, canvas effects and long, iterated prompts.

## Component and asset libraries

Take one component, background or texture into a page you've already designed. Don't let a library pick the style: run what you take through the default look and the house rules.

- [21st.dev](https://21st.dev): React components and backgrounds to drop in.
- [Arc UI](https://uiarc.dev): animated React components and blocks for shadcn and Next.js. Add them with the shadcn CLI or through its MCP server. Free components and a paid Pro tier.
- [Bencho](https://bencho.dev): interactive React components and micro-interactions, live, to explore and tweak before you take them.
- [HorizonX](https://horizonx.so): animated shader backgrounds, textures, mockups, Figma UI kits and React components, with an MCP server. Free and paid.
- [Grainient](https://grainient.supply): gradients, animated gradients, grainy textures and a shader tool. Free and paid. One gradient as the signature moment, never one behind every section.
- [Aceternity UI](https://ui.aceternity.com): 200+ copy-paste React components, blocks and templates with Tailwind and Motion. Free and paid. Many of its effects (aurora, spotlight, background beams, glowing borders) are the gradient-and-glow look the house rules ban: take the mechanics, not the look.
- [ObsidianUI](https://obsidianui.dev): open source React and Tailwind components, blocks and landing templates.
- [Jiro](https://jiro.build): 1,500+ real designs, each with a prompt and its source code. Free and paid.
- [uberdesigner](https://uberdesigner.ai): website templates and UI components, each with a prompt for Claude, Codex or Cursor, the project and a Figma file. Free prompts with an account, paid for more. A template is everyone's starting point: change the direction before you ship it.
