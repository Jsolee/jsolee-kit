# The 20 slop signals

A list of AI-design tells that went around in November 2026. Step 06 checks every page against it. One hit can be a choice; three is the default look coming back.

| # | Signal | What to look for | Do instead |
|---|---|---|---|
| 1 | Tags and pills | Chips, badges and "New" pills around words that aren't controls | Plain text, or nothing. A pill only for a filter or a status the user acts on |
| 2 | Excessive italics | An italic phrase inside the headline, italics for emphasis | Roman type. Emphasis comes from size or weight |
| 3 | Instrument Serif | Instrument Serif, or any serif display set against a neutral sans | A face from a specific place (see Commit in `SKILL.md`) |
| 4 | Negative kerning | Negative tracking under 48 px, or tighter than `-0.03em` anywhere | Tracking 0 for text and UI, `-0.01em` to `-0.02em` on display type |
| 5 | Over-the-top detailed UI | Fake chrome: status rows, version tags, timestamps, LIVE dots, metadata nobody asked for | The real interface at a size you can read |
| 6 | Overusing dividers | A hairline between every row, section or nav item | Space and alignment. A rule only where two groups would merge |
| 7 | Color shades and opacities | One color at `/5`, `/10`, `/20`, `/40` for text, fills and borders | A small named palette: background, ink, muted ink, one accent, all solid |
| 8 | Containers with borders | Every group in a bordered box | Group with space and type. A card only for a separate object: a plan, an item, a message |
| 9 | Overly detailed diagrams | Node graphs, flow charts or architecture maps as decoration | The product doing the thing, or one simple figure for one idea |
| 10 | Verbose, redundant text | A subtitle that repeats the headline, three sentences where one works | A headline and one sentence. Cut every line a reader wouldn't miss |
| 11 | Code breadcrumbs | File paths, `// comments`, `$` prompts, `~/` or `src/` labels as ornament | Real code only when the product is code and the reader needs it |
| 12 | Section numbering | 01, 02, 03 on sections whose order doesn't matter | Numbers only for real steps or rankings |
| 13 | Eyebrows | A small label above every heading | No eyebrow by default. At most one on the page, and only when it adds a fact |
| 14 | Dithering | Dithered or halftone images as a style | Photos and UI at full quality, unless the brand is built on print |
| 15 | ASCII images | ASCII art, box-drawing characters as decoration | A real image, or none |
| 16 | Squircles | A rounded tile behind every icon | The icon alone, aligned to its text |
| 17 | Excessive mono fonts | Mono for labels, captions, nav or body | Mono only for code, tabular figures and what the user types |
| 18 | ALL CAPS subtitles | Uppercase subtitles, labels or kickers with wide tracking | Sentence case. Caps only for display words that are the page's one move |
| 19 | Gradient backgrounds | Color fades, mesh or aurora gradients behind sections | Flat fields. Gradients used as patterns (stripes, dots, rules) are fine |
| 20 | Periods in titles | A full stop at the end of a heading, button, label or card title | No period. If a title needs two sentences, rewrite it as one |
